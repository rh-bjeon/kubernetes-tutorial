Service를 생성합니다.
[#create-service]
[.console-input]
[source,bash,subs="+macros,+attributes"]
----
cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: Service
metadata:
  name: the-service
spec:
  selector:
    app: quarkus-demo
  ports:
    - protocol: TCP
      port: 80
      targetPort: 8080
  type: LoadBalancer
EOF
----

== Ingress 또는 Route

**Kubernetes Ingress**와 **OpenShift Route**는 애플리케이션을 외부에 노출하는 데 사용되는, 기능적으로 유사한 리소스입니다.

`Route` 객체는 Kubernetes Ingress API가 완전히 성숙하기 전에 Red Hat이 개발했습니다. 트래픽 규칙 정의와 그 구현(내장된 HAProxy Router를 통해)을 하나의 통합된 기능으로 묶어 제공합니다.

사용 중인 플랫폼에 따라 해당하는 경로로 진행하세요:

. <<#_kubernetes_ingress,Kubernetes Ingress>>
. <<#_openshift_route,OpenShift Route>>

=== Kubernetes Ingress

[#create-ingress]
[.console-input]
[source,bash,subs="+macros,+attributes"]
----
cat <<EOF | kubectl apply -f -
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: myingress
spec:
  rules:
  - host: stuff-myspace.apps.gcp.burrsutter.dev
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: the-service
            port:
              number: 80
EOF          
----

[#curl-services-ingress]
[.console-input]
[source, bash]
----
curl stuff-myspace.apps.gcp.burrsutter.dev
----

[.console-output]
[source,bash]
----
Supersonic Subatomic Java with Quarkus quarkus-demo-deployment-5979886fb7-gdtnz:2
----

Minikube를 사용하는 경우에는 다음을 참고하세요: https://kubernetes.io/docs/tasks/access-application-cluster/ingress-minikube/

ingress를 제거합니다:

[#delete-ingress]
[.console-input]
[source,bash,subs="+macros,+attributes"]
----
kubectl delete ingress myingress
----

=== OpenShift Route

[#expose-service]
[.console-input]
[source,bash,subs="+macros,+attributes"]
----
oc expose service the-service
oc get routes
----

[.console-output]
[source,bash]
----
NAME          HOST/PORT                                     PATH   SERVICES      PORT   TERMINATION   WILDCARD
the-service   the-service-myspace.apps.gcp.burrsutter.dev          the-service   8080                 None
----

그런 다음 service에 요청을 보냅니다:

[#curl-services-route]
[.console-input]
[source, bash]
----
curl the-service-myspace.apps.gcp.burrsutter.dev
----

[.console-output]
[source,bash]
----
Supersonic Subatomic Java with Quarkus quarkus-demo-deployment-5979886fb7-gdtnz:3
----

=== jsonpath로 스크립팅에 필요한 데이터 요소 추출하기

다음 명령은 쿠버네티스 객체를 JSON 형식의 파일로 덤프합니다:

[.console-input]
[source,bash]
----
oc get route the-service -o json > myroutes.json
----

JSONPath 문법을 사용해서 JSON에서 특정 정보만 추출할 수도 있습니다.

[#route-jq]
[.console-input]
[source, bash]
----
oc get route the-service -o jsonpath="{.spec.host}"
----

[.console-output]
[source, bash]
----
the-service-myspace.apps.gcp.burrsutter.dev
----
