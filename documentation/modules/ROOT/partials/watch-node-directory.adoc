
`minikube ssh` 명령을 사용해서 쿠버네티스 노드에 연결하는 것을 시뮬레이션해 봅시다. (minikube에는 노드가 하나만 실행됩니다)

[.console-input]
[source,bash]
----
minikube ssh
----

[.console-output]
[source,bash,subs="+macros,+attributes"]
----
Last login: Tue Jul 13 08:26:18 2021 from 192.168.49.1
docker@devnation:~$
----

이제 노드에 접속했으니, Pod가 ``/tmp/demo``로 마운트한 `{mount-dir}` 디렉터리를 지켜봅시다.
